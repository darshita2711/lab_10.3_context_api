
## Reflection – Context API Implementation

## What I Learned

In this lab, I learned how to use the Context API to share data between React components without passing props through multiple levels.

I created three contexts for todos, filters, and themes.

I also practiced using useState, useEffect, useMemo, and useCallback.

I learned how to create custom hooks to make accessing context data easier and reduce repeated code.

## Challenges I Faced

One challenge was understanding how Context Providers work and how components receive shared data.

I also had some difficulty understanding how to update arrays using map() and filter().

Another challenge was understanding how localStorage saves data and how useEffect updates it when state changes.

## How I Solved Them

I worked through the application step by step and tested each feature in the browser.

I practiced using map() to update todos and filter() to remove or display specific todos.

I also used custom hooks to simplify the code and make it easier to reuse.

## What I Enjoyed

I enjoyed building the Todo application because I could see how React components communicate with each other.

I especially liked implementing the theme switcher and saving todos in localStorage so the data remains after refreshing the page.

## What I Want to Improve

I want to practice Context API more and become more comfortable with custom hooks, useMemo, and useCallback.
I also want to improve my understanding of state management in larger React applications.

## Conclusion

This lab helped me understand how to manage shared state in React using the Context API.
It also improved my confidence in building applications with React and TypeScript.
